# Сборка Android APK

Проект собирается через Buildozer:

```bash
buildozer android debug
```

Готовый APK появится в `bin/`.

## Важно про подключение к базе данных

Приложение использует PostgreSQL напрямую через SQLAlchemy. На Android `localhost`
указывает на сам телефон, а не на компьютер с PostgreSQL. Поэтому перед запуском
APK необходимо указать доступный из телефона адрес сервера БД через переменные
`DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` в окружении сборки/запуска.
Порт PostgreSQL должен быть доступен в локальной сети, а сервер должен разрешать
подключения с телефона.

В исходном коде имя SQLAlchemy-драйвера было `postgresql+psycopg`, но в Android
зависимостях указан `psycopg2`. Оно приведено к `postgresql+psycopg2`, чтобы
соответствовать установленному пакету.

> Сборка APK не проверяет доступность PostgreSQL. Для проверки работы приложения
> после установки нужен доступный сервер БД с подготовленной схемой и справочниками.
